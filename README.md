# Meridian

**Meridian** is an AI-native ERP platform — CRM, project management, and business tools powered by intelligent agents. Built for businesses of all sizes with easy migration from Odoo and other ERPs.

See the full codebase at https://github.com/f-calle/f-calle/tree/fc/meridian-erp-301e while this repository is being synced.

## Quickstart

```bash
./scripts/dev-setup.sh
pnpm --filter @meridian/api dev
pnpm --filter @meridian/web dev
```
